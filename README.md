## Overview

Squad Mortar Calculator is an essential tool for Squad mortar crews, computing precise bearing and elevation solutions from a keypad-based coordinate system. Enter friendly mortar position and target grid, and the calculator outputs the exact milliradians elevation and bearing needed for a first-round impact, accounting for terrain height difference.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Squad Mortar Calculator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Grid Coordinates** | Accepts Squad keypad grid coordinates for both mortar and target |
| **Elevation Calc** | Accounts for altitude difference between mortar and target position |
| **Instant Solution** | Returns bearing and elevation simultaneously for immediate firing |
| **Spread Indicator** | Shows shot dispersion radius at the target distance for adjustment |
